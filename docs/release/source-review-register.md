## Review completion contract

For each retained source, prepare reviewed B-03 JSON and a runtime mapping. Record exact population, comparator (explicit null if unreported), outcome direction and timing, source-role claims, claim locators, sample/study counts, limitations, licence/access disposition, reviewer and date. Review overlapping evidence syntheses as overlapping evidence, not independent replication. Replace excluded candidates with credible sources; the target is not a reason to lower standards.
