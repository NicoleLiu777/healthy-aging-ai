## C. Final answer review and exact release approval

After the repository builds a candidate from the accepted sources, Nicole reviews nine newly generated decision briefs. Every unresolved `edit` or `reject` blocks release. Only then is a new approval file generated containing the exact release, code, coverage-suite, gold-set, rollback corpus, and rollback code hashes. Nicole checks those values and signs the dated approval.

Production activation remains a separate B-12 operation with live acceptance checks and paired code/data rollback. Quarantined and licence-unknown records cannot enter the release.
